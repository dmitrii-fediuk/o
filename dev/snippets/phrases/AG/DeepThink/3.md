#
Когда лимит истекает, DeepThink сбрасывается до тупой модели.
Все такие ответы игнорируй: заново поручай задачу следующем профилю.

#
Профили используй рационально: в первую очередь поручай задачу тому, у кого раньше лимит истекает.

#
Вообще, если осталось меньше 10% — то не поручай этому профилю задачи: DeepThink обычно больше расходует. 

#
Вопросы и ответы для DeepThink логируй аналогично твоим: в `req` и `res` внутри папки DeepThink.
