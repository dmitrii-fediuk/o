# `᛭T`
Действуй пошагово
##
Найди ранее невыявленные `R⬆⠿`.
##
Проанализируй их.
Для этого для каждого  `R⬆ᵢ` выяви:
- Его недостатки
- Его достоинства
- Дай оценку `R⬆ᵢ` по шкале от 0 до 100.
##
Выскажи свой вердикт.

# Требования к ответу / Форматирование
Свой перечень ранее невыявленных `R⬆⠿` оформляй точно так же, как оформлен перечень ранее выявленных `R⬆⠿`.
Твой перечень должен быть дополнением к `R⬆⠿` и использовать сквозную с ним нумерацию.
