# 
Есть ли пункте STUB языковые ошибки?
##
Свои замечания высказывай по пунктам.
##
Для каждого своего замечания указывай свой вариант полного предложения, не куска фразы.
##
Не разбивай одно исходное предложение на несколько.
##
К кавычкам не придирайся.
##
Не предлагай записывать числа словами.
##
Не делай менять формат чисел
##
Не используй сокращения типа «don't».
##
Не придирайся к «How to + глагол».
##
Полностью сохрани стилистику.
##
Не делай текст более вежливым.
