# 5. Требования к `T๏`
##
`T๏` должен содержать слова: «STUB», «STUB», «STUB».
## 
`T๏` должен быть на английском языке.
## 
Не пиши каждое слово с заглавной буквы. 
Вместо этого пиши нормальным образом, как обычное предложение.
## 
Не используй в `T๏` двоеточие (`:`).
##
Используй §1 моего запроса, чтобы понять:
- Контекст

##
Используй §2 моего запроса, чтобы понять:
- Мой стиль письма
- Мою лексику

##
Свои замечания высказывай по пунктам.
##
До списка замечаний ничего не пиши.
##
Нумерация замечаний должна быть сквозной.
Номера должны быть заголовками 1-го уровня (посредством `#`).
##
Не ставь после заголовков пустые строки, пидорас!
### Неправильное форматирование
```markdown
# Заголовок

Текст
```
### Правильное форматирование
```markdown
# Заголовок
Текст
```
##
Для каждого своего замечания указывай свою степень уверенности в нём по шкале от 0 до 100:
- 0 означает, что твоё замечание безосновательно (ошибочно).
- 100 означает, что ты полностью уверен в правоте своего замечания.
##
Для каждого своего замечания указывай свой вариант полного предложения, не куска фразы.
##
После списка замечаний предложи свой вариант улучшения, который учитывает все твои замечания.
##
Не разбивай одно исходное предложение на несколько.
##
Полностью сохрани стилистику.
##
Не делай текст более вежливым.
##
Не придирайся к кавычкам `«»`.
##
Не придирайся к символам-стрелкам (`⬌`, `→`, etc.).
##
Не предлагай исправлять цитаты.
##
Не предлагай записывать числа словами.
##
Не предлагай менять формат чисел.
##
Не используй сокращения типа «don't».
###
Исключением являются случаи, когда такие сокращения уже присутствуют в моём тексте: их не убирай.
