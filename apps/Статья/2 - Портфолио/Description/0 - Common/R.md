# Требования к `᛭ᗪᵢ`
## 
`᛭ᗪᵢ` не должен быть длиннее 75 символов.
##
`᛭ᗪᵢ` — это, по сути, потенциальные заголовки для `᛭A`.
##
Разные `᛭ᗪᵢ` не должны повторять смысл друг друга.
Вместо этого каждый `᛭ᗪᵢ` должен описывать свой аспект `᛭A`.
## 
Не пиши каждое слово `᛭ᗪᵢ` с заглавной буквы. 
Вместо этого пиши нормальным образом, как обычное предложение.
## 
Не используй в `᛭ᗪᵢ` двоеточие (`:`).
## 
В качестве кавычек используй `«»`.
## 
Старайся, чтобы `᛭ᗪ` не упускал ни одного ключевого аспекта `᛭A`.
Другими словами, `᛭ᗪ` не должен быть однобоким, упоминая только некоторые ключевые аспекты `᛭A` и полностью игнорируя другие.
